# FINAL FEM / Guyer–Krumhansl Identifiability — Research Package

A single, self-contained, curated package for the paper:

> **When Two Thermal Parameters Become One: Structural Non-Identifiability of the
> Guyer–Krumhansl Relaxation–Nonlocality Pair at the Fourier Resonance**
> — V. Gupta, Gurugram University.

This package contains the final manuscript, its bibliography, its figures, the
computational program that produced the reported results, the scientific input
data, and the figure-generation code. It is *not* an archive of the development
history of the project; every development artifact, duplicate, old version,
cache and intermediate build output has been removed.

## 2. Which file is the main manuscript

**`manuscript/FINAL_MANUSCRIPT.tex`** is the single authoritative manuscript
source. It is the only `.tex` manuscript retained; no draft, backup or earlier
manuscript version is included.

- Document class: `elsarticle` (Elsevier), `preprint` mode.
- Compile sequence: `pdflatex → bibtex → pdflatex → pdflatex`.
- References: `\bibliography{references}` with style `elsarticle-num`.

## 3. Which bibliography is used

**`manuscript/references.bib`** — a single bibliography file (57 entries) that
covers every citation in the manuscript with no unresolved keys. There is one
authoritative bibliography set; nothing is split across duplicate files.

## 4. Which program is the main computational entry point

**`code/main/scripts/run_all.py`** is the main entry point. It runs, in order:
symbolic cross-checks, unit tests, acceptance tests T1–T24, the anchor
validation, the full identifiability/Monte-Carlo/BIC/calibration analysis, and
figure generation.

A fast smoke run (skips the slow Monte-Carlo and BIC) is also available:

```bash
cd code/main
GK_FAST=1 python3 scripts/run_all.py     # Linux / macOS
# PowerShell:
$env:GK_FAST=1; python .\scripts\run_all.py; Remove-Item Env:\GK_FAST
```

## 5. Supporting programs

- `code/main/src/*.py` — the solver modules (`forward.py`, `fd_solver.py`,
  `laplace.py`, `limits.py`, `model.py`, `statistics.py`, `analysis.py`,
  `calibration.py`, `validation.py`, `symbolic.py`). All are required.
- `code/main/scripts/run_acceptance.py` — acceptance tests T1–T24.
- `code/main/scripts/run_validation.py` — anchor validation of the forward operator.
- `code/main/scripts/run_analysis.py` — identifiability / MC / BIC / calibration.
- `code/main/scripts/generate_figures.py` — the program's own figures (F1–F7).
- `code/main/scripts/regenerate_fig2_digitisation.py` — optional re-digitisation of Fig. 2.
- `code/plotting/matlab/run_all_figures.m` — regenerates the 11 **manuscript** figures.

## 6. Where material / input data are located

- **Digitised published curves (read-only inputs):** `data/input/*.npy`.
  These are the digitised data from the published anchor figures and are
  treated as scientific input data, not program output.
- **Source raster for Fig. 2:** `data/input/p10_fig2.png`.
- **Program configuration / parameters:** `code/main/config/*.json`.
- **Verified figure-data CSVs (read by MATLAB figures):** `data/results/*.csv`
  (14 files: F1, F2, F3, F5, F6, F7, `anchor_metrics`, `bands`,
  `calibration_results`, `fd_convergence_windows5`, `identifiability_results`,
  `monte_carlo_results`, `series_convergence`, `talbot_parity`).
- **Program's own outputs (regenerated by `run_all.py`):** `code/main/results/`,
  `code/main/acceptance/`, `code/main/figures/`. These are produced on any run
  and are not shipped as pre-built duplicates; the reference figure-data they
  draw on lives in `data/results/`.

The path resolution in the code is position-independent (`gk_paths.m` and the
Python `PROJECT/data/...` helpers), so the package can be unpacked anywhere.

## 7. How the main calculations are reproduced

1. Install dependencies: `pip install numpy scipy sympy matplotlib pytest`
   (add `pillow` only for the optional Fig. 2 re-digitisation).
2. From `code/main`, run `python3 scripts/run_all.py` (or `GK_FAST=1` for the
   fast smoke run).
3. The program validates the forward operator against the published anchor
   figures (target NRMSE **0.384 % / 0.382 % / 0.483 %**), reproduces the
   acceptance values (band edges **0.628 / 1.804**, `B`=**1.53218** for Both
   et al.), and writes its outputs under `results/`, `acceptance/`, `figures/`.

## 8. How the figures are regenerated

The **manuscript's 11 figures** are produced by the MATLAB package:

```matlab
cd <package>/code/plotting/matlab
run_all_figures          % writes PDF/EPS/PNG into matlab/output/
```

This package was audited for MATLAB R2020 compatibility (its README documents a
graphics-handle preallocation fix and a `fig08`/`fig07` fix). The 11 output PDFs
should then be copied into `manuscript/figures/` for the next recompile. The
program's own companion figures (F1–F7) are generated by
`code/main/scripts/generate_figures.py`.

## 9. Software / environment requirements

- **Manuscript:** a TeX Live distribution with the Elsevier `elsarticle` class
  and `elsarticle-num` bibliography style, plus `amsmath`, `amssymb`, `amsthm`,
  `bm`, `graphicx`, `booktabs`, `tabularx`, `caption`, `algorithm`,
  `algpseudocode`, `xcolor`, `hyperref`, `cleveref`, `microtype`, `siunitx`.
- **Computational program:** Python 3.10+, `numpy`, `scipy`, `sympy`,
  `matplotlib`, `pytest` (optional `pillow`).
- **Figure generation:** MATLAB R2020a/R2020b (or Octave).

```
1. Compile the manuscript        -> manuscript/FINAL_MANUSCRIPT.tex

```

### Provenance & scope note

The program and the master calculation record explicitly exclude (by design)
thermoelasticity, piezoelectricity, two-temperature theory, fractional or
memory-dependent derivatives, Rabotnov kernels, porosity, semiconductor
coupling, nonlocal elasticity and MGT. The claim is about the structural
non-identifiability of the Guyer–Krumhansl pair; **no experimental validation
of the inverse conclusions is claimed.**
