## Instructions for Overleaf Upload

1. Upload the contents of this folder (or zip archive) to an [Overleaf](https://www.overleaf.com/) project.
2. Set `main.tex` as the main document.
3. In Project Settings, ensure the compiler is set to **pdfLaTeX** (default) or **LaTeX**.
4. Click **Compile**.
5. All figures, references, and style files are local to this folder:
   - `figures/`: Vector PDF and 300-DPI PNG figures.
   - `references.bib`: Complete BibTeX bibliography with DOIs.
   - `elsarticle-num.bst`: Bundled BibTeX style file.

No external paths, parent directories, or system-wide TeX packages beyond standard LaTeX are required.
