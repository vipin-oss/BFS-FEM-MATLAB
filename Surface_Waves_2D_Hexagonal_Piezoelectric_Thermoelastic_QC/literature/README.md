# literature/ — metadata-only literature package

Copyrighted journal articles are NOT redistributed in this archive. Each
category folder lists the references (BibTeX keys from
`literature/all_references.bib` = exact manuscript bibliography, 47 entries)
with their role in the paper. Retrieve any entry from the publisher via its
DOI or the cited venue/volume/pages in the .bib.

`sample_papers/GK_Heat_style_reference.pdf` is a style-reference sample
provided by the author of this project (not a source of results).
