## EPS companions (GitHub archival, 2026-09-07)

`FigNN.eps` (pdftops conversions of the authoritative `figN.pdf`; mapping
Fig01↔fig1 … Fig11↔fig11). All are valid Level-2 vector PostScript;
regeneration is byte-deterministic (verified clean-room). Exception noted:
Fig10/fig10 carries ONE rasterized colour-mesh layer embedded by
matplotlib's PDF backend (pcolormesh exact-cell plot); it is identical in
the PDF and the EPS, so the PDF↔EPS pair loses nothing. PDFs remain the
authoritative format.
