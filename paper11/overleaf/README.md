## Instructions for Overleaf Upload

1. Download `Paper11_Overleaf_Ready.zip` from the repository root.
2. Log in to [Overleaf](https://www.overleaf.com/).
3. Click **New Project** -> **Upload Project**.
4. Select `Paper11_Overleaf_Ready.zip`.
5. In the Overleaf project settings, select **pdfLaTeX** or **LaTeX** engine with `main.tex` as the root document.
6. Click **Recompile**.

The package includes:
- `main.tex`: Full article manuscript with standard Elsevier / applied mathematics formatting.
- `references.bib`: Complete BibTeX bibliography with all cited literature.
- `figures/`: Vector PDF and 300-DPI raster PNG figures referenced in the text.
